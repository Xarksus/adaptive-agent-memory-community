# Adaptive Agent Memory Pro

Adaptive Agent Memory Community gives AI agents local experience memory. **Pro** adds decision learning on top: it uses prior outcomes to recommend which actions or tools should be preferred next.

## Pro features

- outcome-based action recommendations
- adaptive weighting from success and failure
- prediction-error reliability weighting
- candidate-action filtering
- recommendation confidence
- global action-performance analytics
